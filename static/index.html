Privacy & Help

How to use it

Upload an original PDF (v1) and a revised PDF (v2), or click Load Sample Demo to try it with example contracts. Click Generate Redline Comparison to see tracked changes. Use Unified Redline for a single marked-up document, or Synchronized Side-by-Side to view both versions next to each other as formatted text or rendered PDF pages. Use the change navigator (< / >, or Shift+J / Shift+K) to jump between edits, and the filter/search box to narrow down what you're looking at.

Privacy

Both PDFs are parsed and compared entirely inside your browser using PDF.js and diff-match-patch. Your documents are never uploaded to a server — the app makes no network request containing your document content. The only server calls this tool makes are to load its own static files and (optionally) the small demo sample PDFs.

Limitations

  • Text extraction quality depends on how the PDF was produced. Scanned/image-only PDFs contain no extractable text yet — OCR support is on the roadmap.
  • Heading and paragraph detection is inferred from font size and layout, and can misfire on unusual formatting (multi-column layouts, heavy custom styling, tables).
  • The PDF Canvas View highlight overlay is an approximate, word-matching visual aid — it is not a precise mapping of every diff and should not be relied on as the definitive record of changes. Use the Unified Redline view for that.
  • Statistics (match score, added/deleted words) are computed from word-level text diffing and are a useful estimate, not a certified legal redline count.
