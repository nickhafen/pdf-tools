Info

How to use it

Upload an original PDF (v1) and a revised PDF (v2), or click Load Sample to try it with example contracts. Click Generate Redline Comparison to see tracked changes. Each pane can independently show the Original (v1), Revised (v2), or Redline, displayed as Formatted text, Plain Text, or the actual PDF Canvas. Results open in Compare Side-by-Side (original on the left, redline on the right); switch to Single View for the redline alone at full width. Each pane scrolls on its own; turn on Sync Scroll to scroll two text panes together, lined up by matching section headings. Use Swap v1/v2 to flip which document is which, and Reset to start over. Use the change navigator (< / >, or Shift+J / Shift+K) to jump between edits — active whenever at least one visible pane shows the Redline — and the search box to filter by keyword. Press Esc to close any open dialog.

Privacy

Both PDFs are parsed and compared entirely inside your browser using PDF.js and diff-match-patch. Your documents are never uploaded to a server — the app makes no network request containing your document content. The only server calls this tool makes are to load its own static files and (optionally) the small demo sample PDFs.

Limitations

  • Text extraction quality depends on how the PDF was produced. Scanned/image-only PDFs contain no extractable text yet — OCR support is on the roadmap.
  • Heading and paragraph detection is inferred from font size and layout, and can misfire on unusual formatting (multi-column layouts, heavy custom styling, tables).
  • The PDF Canvas display shows the original, unmodified PDF page — it does not highlight changes. Use the Redline content (Formatted or Plain Text) to see tracked changes.
  • Statistics (match score, added/deleted words) are computed from word-level text diffing and are a useful estimate, not a certified legal redline count.
  • PDF export renders the formatted redline through your browser (no server involved), so very long or complex documents may paginate imperfectly. For a pixel-perfect copy, use your browser's print dialog on the Standalone HTML export instead.
